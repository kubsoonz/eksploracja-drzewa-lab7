# Laboratorium 7 – Drzewa decyzyjne

Projekt zawiera wykonany notatnik Z1–Z10, odpowiedzi D1–D3 oraz aplikację Streamlit.

## Uruchomienie w GitHub Codespaces
1. Otwórz repozytorium przez Code → Codespaces → Create codespace on main.
2. W terminalu wykonaj `pip install -r requirements.txt`.
3. Otwórz `lab7_student.ipynb`, wybierz Python 3 i uruchom **Restart Kernel and Run All Cells**.
4. W terminalu wykonaj `streamlit run app.py` i otwórz port 8501.
5. W aplikacji przetestuj 1 zamówienie i 200 dni; wynik ok. 86%, decyzja: wyślij kupon.
6. Zapisz: `git add .`, `git commit -m "Laboratorium 7"`, `git push`.
7. Na Render utwórz Web Service z tego repozytorium (ustawienia w `render.yaml`). Wklej adres aplikacji i repozytorium do pracy.

Dane są syntetyczne, a skuteczność kuponów opiera się na założeniach z polecenia.
